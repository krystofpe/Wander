# Wander

A lone hooded wanderer walks forever through pixel-art lands made up as he goes, while day turns to night and the land slowly changes around him. Nobody plays it: it is something to look at, or to leave running full screen on a second monitor.

This branch (`feat/wanderer`) is being rebuilt as a browser app; see `docs/superpowers/specs/2026-10-10-wander-wanderer-design.md` for the design and `docs/research/wanderer-research.md` for the research behind it. This README is rewritten when the work is done.
